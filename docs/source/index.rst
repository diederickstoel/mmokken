mmokken — multidimensional non-parametric measurement models
============================================================

``mmokken`` is a Python package for non-parametric and parametric measurement
models. The first release targets numerical parity with the R `mokken` package
on the unidimensional core; subsequent releases add the multidimensional
Stoel-H regime and parametric IRT families (Rasch, 2PL, GRM, md-2PL) under a
unified estimator API.

This is **alpha** software. The public API is being stabilised against the
research programme described in ``docs/research_proposal.docx``.
